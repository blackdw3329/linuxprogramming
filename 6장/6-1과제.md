## 2. 다음 2가지 명령어의 차이는 무엇인가?

```bash
$ find . -name '*.txt'
$ find . -name *.txt
```

> 첫 번째는 따옴표로 `*`의 셸 확장을 막아, `find`가 현재 디렉터리와 모든 하위 디렉터리에서 이름이 `.txt`로 끝나는 항목을 검색하도록 합니다.
> 두 번째는 명령어 실행 전에 셸이 현재 디렉터리의 파일 이름으로 `*.txt`를 확장합니다.

## 3. --help 옵션을 사용하여 명령어의 사용법을 출력하는 예제를 만들어보라

> `ls --help`를 실행하면 `ls`의 사용 형식과 옵션 설명을 출력합니다. `--help` 지원 여부는 명령어에 따라 다릅니다.

```bash
ls --help
```

## 4. man 명령어로 명령어의 사용법을 출력하는 예제를 만들어보라

> `man cp`를 실행하면 `cp`의 사용법, 옵션 등을 설명하는 매뉴얼을 확인할 수 있습니다. 일반적으로 방향키로 이동하고, `/검색어`로 검색하며, `q`로 종료합니다.

```bash
man cp
```

## 5. cd, ls, cp, rm, ifconfig 명령어의 실행파일이 존재하는 경로를 조사하라.

> Bash에서 `type`은 명령어가 내장 명령인지 실행 파일인지 확인하고, `type -P`는 `PATH`에서 실행 파일의 경로를 찾습니다. `cd`는 현재 셸의 작업 디렉터리를 변경하는 내장 명령이므로 일반적으로 별도의 실행 파일이 없습니다. 나머지 경로는 배포판과 설치 상태에 따라 달라집니다.

```bash
type cd
type -P ls cp rm ifconfig
```

| 명령어 | 일반적인 실행 파일 경로 또는 형태 |
|---|---|
| `cd` | 셸 내장 명령 |
| `ls` | `/usr/bin/ls` 또는 `/bin/ls` |
| `cp` | `/usr/bin/cp` 또는 `/bin/cp` |
| `rm` | `/usr/bin/rm` 또는 `/bin/rm` |
| `ifconfig` | `/usr/sbin/ifconfig` 또는 `/sbin/ifconfig` |

> 위 표는 일반적인 경로이며 실제 환경에서 확인한 결과는 아닙니다. `ifconfig`는 `net-tools` 패키지가 설치되지 않았거나 해당 경로가 `PATH`에 없으면 검색되지 않을 수 있습니다.
