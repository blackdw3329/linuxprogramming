
## 실습과제1

### 1. 프로그램 개발과정 편집->선행처리->컴파일->링크->실행 단계를 자세히 설명하시오.

> **① 편집(Edit)**
> C언어로 프로그램의 소스코드를 작성하는 단계이다. 텍스트 에디터를 사용하여 작성하며, 확장자가 `.c`인 소스파일이 생성된다.
>
> **② 선행처리(Preprocessing)**
> 컴파일 전에 수행되는 단계로, `#include`를 이용한 헤더파일 포함, `#define`을 이용한 매크로 치환, 조건부 컴파일 등의 작업을 수행한다.
>
> **③ 컴파일(Compile)**
> 선행처리가 완료된 C언어 소스코드를 기계어로 변환하는 단계이다. 컴파일러에 의해 목적파일(`.obj` 또는 `.o`)이 생성된다.
>
> **④ 링크(Link)**
> 여러 목적파일과 라이브러리를 연결하여 하나의 실행파일을 생성하는 단계이다. 링커(Linker)가 이 작업을 수행한다.
>
> **⑤ 실행(Execute)**
> 생성된 실행파일을 컴퓨터가 수행하는 단계이다. 로더(Loader)가 실행파일을 메모리에 적재하고 프로그램을 실행한다.

### 2. 프로젝트 빌드 후 소스파일(c), 목적파일(obj), 실행파일(exe)의 위치를 찾아보라 -> 파일탐색기 검색화면을 첨부할 것

## 실습과제2

### 1. 매크로 상수를 사용한 예제를 인터넷에서 찾아서 실행해보고 소스코드를 자세히 설명하라.

> 매크로 상수는 `#define` 지시자를 이용하여 숫자나 문자열에 의미 있는 이름을 부여하는 기능이다.
>
> 선행처리 과정에서 매크로 이름이 정의된 값으로 치환되므로 코드의 가독성이 향상되고 유지보수가 쉬워진다.

**① 프로젝트 디렉터리 생성**

```bash
mkdir -p ~/ch31/task2
cd ~/ch31/task2
nano main.c
```

**② 소스코드: main.c**

```
#include <stdio.h>  // 표준 입출력 함수 선언
#define BUFFER_SIZE 1024  // 버퍼 크기를 매크로 상수로 정의

int main(void) {  // 프로그램 시작
    printf("버퍼 크기: %d\n", BUFFER_SIZE);  // 매크로 상수 출력
    return 0;  // 프로그램 정상 종료
}
```

> `#include <stdio.h>`는 `printf()` 함수를 사용하기 위해 헤더파일을 포함한다.
>
> `#define BUFFER_SIZE 1024`는 BUFFER_SIZE를 1024로 정의한다.
>
> `printf()`는 매크로 상수의 값을 출력한다. 선행처리 과정에서 BUFFER_SIZE는 1024로 치환된다.

**③ 컴파일 및 실행**

```bash
gcc main.c -o program
./program
```

## 실습과제3

### 1. #if ~#elif~ #endif 지시자를 사용하는 이유를 설명하라.

> `#if`, `#elif`, `#endif`는 조건에 따라 특정 소스코드를 선택적으로 컴파일하기 위해 사용하는 선행처리 지시자이다.
>
> `#if`는 첫 번째 조건을 검사하고, `#elif`는 이전 조건이 거짓일 경우 다른 조건을 검사한다.
>
> 일반적인 `if`문은 프로그램 실행 중에 조건을 검사하지만, 조건부 컴파일 지시자는 컴파일 전에 포함할 코드를 결정한다.

### 2. #if ~#elif~ #endif 지시자를 사용한 예제를 인터넷에서 찾아서 실행해보고 소스코드를 자세히 설명하라.

**① 프로젝트 디렉터리 생성**

```bash
mkdir -p ~/ch31/task3
cd ~/ch31/task3
nano main.c
```

**② 소스코드: main.c**

```c
#include <stdio.h>  // 표준 입출력 함수 선언
#define HIT_NUM 7  // 매크로 상수 HIT_NUM 정의

int main(void) {  // 프로그램 시작
#if HIT_NUM == 5  // HIT_NUM이 5인지 검사
    puts("매크로 상수 HIT_NUM은 현재 5입니다.");
#elif HIT_NUM == 6  // HIT_NUM이 6인지 검사
    puts("매크로 상수 HIT_NUM은 현재 6입니다.");
#elif HIT_NUM == 7  // HIT_NUM이 7인지 검사
    puts("매크로 상수 HIT_NUM은 현재 7입니다.");
#else  // 모든 조건이 거짓인 경우
    puts("매크로 상수 HIT_NUM은 5, 6, 7이 아닙니다.");
#endif  // 조건부 컴파일 종료

    return 0;  // 프로그램 정상 종료
}
```

> `#define HIT_NUM 7`은 매크로 상수를 7로 정의한다.
>
> `#if`와 `#elif`는 HIT_NUM의 값을 순서대로 비교한다.
>
> HIT_NUM이 7이므로 세 번째 조건이 참이 되어 해당 출력문만 컴파일된다.
>
> `#endif`는 조건부 컴파일을 종료한다.

**③ 컴파일 및 실행**

```bash
gcc main.c -o program
./program
```

**실행 결과**

```text
매크로 상수 HIT_NUM은 현재 7입니다.
```

## 실습과제4

### 1. #ifdef ~ #endif 지시자를 사용하는 이유를 설명하라.

> `#ifdef`는 특정 매크로가 정의되어 있는지 확인하여 소스코드를 선택적으로 컴파일하기 위해 사용하는 지시자이다.
>
> 매크로가 정의되어 있으면 해당 코드를 포함하고, 정의되어 있지 않으면 제외한다.
>
> 매크로의 값과 관계없이 정의 여부만 검사하며, `#endif`로 조건부 컴파일을 종료한다.

### 2. #ifdef ~ #endif 지시자를 사용한 예제를 인터넷에서 찾아서 실행해보고 소스코드를 자세히 설명하라.

**① 프로젝트 디렉터리 생성**

```bash
mkdir -p ~/ch31/task4
cd ~/ch31/task4
nano main.c
```

**② 소스코드: main.c**

```c
#include <stdio.h>  // 표준 입출력 함수 선언
#define ADD  // ADD 매크로 정의
#define MIN  // MIN 매크로 정의

int main(void) {  // 프로그램 시작
    int num1 = 10, num2 = 20;  // 두 정수 선언 및 초기화

#ifdef ADD  // ADD 매크로가 정의되었는지 검사
    printf("%d + %d = %d\n", num1, num2, num1 + num2);
#endif  // ADD 조건부 컴파일 종료

#ifdef MIN  // MIN 매크로가 정의되었는지 검사
    printf("%d - %d = %d\n", num1, num2, num1 - num2);
#endif  // MIN 조건부 컴파일 종료

    return 0;  // 프로그램 정상 종료
}
```

> `#define ADD`와 `#define MIN`은 두 매크로를 정의한다.
>
> `#ifdef ADD`는 ADD의 정의 여부를 확인하여 덧셈 코드를 포함한다.
>
> `#ifdef MIN`은 MIN의 정의 여부를 확인하여 뺄셈 코드를 포함한다.
>
> 두 매크로가 모두 정의되어 있으므로 덧셈과 뺄셈 결과가 모두 출력된다.

**③ 컴파일 및 실행**

```bash
gcc main.c -o program
./program
```

**실행 결과**

```text
10 + 20 = 30
10 - 20 = -10
```
## 실습과제5

### 1. #ifndef ~ #endif 지시자를 사용하는 이유를 설명하라.

> `#ifndef`는 특정 매크로가 정의되지 않았을 때 해당 소스코드를 포함시키는 조건부 컴파일 지시자이다.
>
> 매크로가 정의되어 있으면 코드를 제외하고, 정의되지 않았으면 코드를 포함한다.
>
> 주로 헤더파일의 중복 포함을 방지하거나 특정 매크로가 정의되지 않은 경우에만 코드를 컴파일하는 데 사용한다.

### 2. #ifndef ~ #endif 지시자를 사용한 예제를 인터넷에서 찾아서 실행해보고 소스코드를 자세히 설명하라.
**① 프로젝트 디렉터리 생성**

```bash
mkdir -p ~/ch31/task5
cd ~/ch31/task5
nano main.c
```

**② 소스코드: main.c**

```c
#include <stdio.h>  // 표준 입출력 함수 선언
#define MIN  // MIN 매크로 정의

int main(void) {  // 프로그램 시작
    int num1 = 10, num2 = 20;  // 두 정수 선언 및 초기화

#ifndef ADD  // ADD가 정의되지 않았는지 검사
    printf("%d + %d = %d\n", num1, num2, num1 + num2);
#endif  // ADD 조건부 컴파일 종료

#ifndef MIN  // MIN이 정의되지 않았는지 검사
    printf("%d - %d = %d\n", num1, num2, num1 - num2);
#endif  // MIN 조건부 컴파일 종료

    return 0;  // 프로그램 정상 종료
}
```

> `#define MIN`은 MIN 매크로를 정의한다.
>
> `#ifndef ADD`는 ADD가 정의되지 않았으므로 덧셈 코드를 포함한다.
>
> `#ifndef MIN`은 MIN이 이미 정의되어 있으므로 뺄셈 코드를 제외한다.
>
> 따라서 덧셈 결과만 출력된다.

**③ 컴파일 및 실행**

```bash
gcc main.c -o program
./program
```

**실행 결과**

```text
10 + 20 = 30
```
