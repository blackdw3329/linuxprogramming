# 실습과제3

## 1. `cat`

> 파일 내용을 한 번에 출력하는 명령어입니다. 짧은 파일을 확인하거나 여러 파일의 내용을 이어서 출력할 때 사용합니다.

```bash
cat file.txt
```

## 2. `less`

> 파일 내용을 화면 단위로 보여주며, 앞뒤로 자유롭게 이동하거나 문자열을 검색할 수 있습니다. 긴 파일을 확인하기에 편리하며, 방향키로 이동하고 `/검색어`로 검색하며 `q`로 종료합니다.

```bash
less file.txt
```

## 3. `more`

> 파일 내용을 화면 단위로 보여주며, 주로 앞으로 넘기면서 읽을 때 사용합니다. `Space`로 다음 화면, `Enter`로 다음 줄을 확인하고 `q`로 종료합니다. `less`보다 이동 기능이 제한적입니다.

```bash
more file.txt
```
