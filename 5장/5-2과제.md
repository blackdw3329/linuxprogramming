# 실습과제4
## 1. 하드링크와 심볼릭 링크의 차이를 설명하라.

> 하드링크는 같은 파일의 inode를 가리키는 또 다른 이름입니다. 원래 이름을 삭제해도 다른 하드링크로 접근할 수 있지만, 다른 파일 시스템으로는 만들 수 없으며 일반적으로 디렉터리에는 만들지 못합니다. 심볼릭 링크는 대상 경로를 저장하는 별도의 파일로, 다른 파일 시스템이나 디렉터리에도 연결할 수 있지만 대상 경로가 사라지면 링크가 끊어집니다.

## 2. 심볼릭 링크를 확인하는 명령어를 설명하라.

> `ls -l`을 실행하면 심볼릭 링크는 파일 종류가 `l`로 표시되고, `링크 이름 -> 대상 경로`가 나타납니다.

```bash
ls -l symlink1
```

## 4. 빈파일과 빈디렉토리를 만든 후 파일속성(ls -l)을 출력하면 아래처럼 디렉터리는 하드링크의 수가 2이고 파일은 1이다. 이유를 설명하라.

> 그림과 같은 일반적인 리눅스 파일 시스템에서 빈 디렉터리는 부모 디렉터리의 이름 항목인 `dir1`과 자기 자신을 가리키는 내부 항목 `.`이 같은 inode를 참조하므로 하드링크 수가 2입니다. 일반 파일은 생성 직후 자신을 가리키는 이름 항목이 하나이므로 하드링크 수가 1입니다. 디렉터리 내부의 `..`는 부모 디렉터리를 가리키며, 파일 내용이 비어 있는지는 하드링크 수와 관계가 없습니다.
