| 기능 | 단축키 |
|---|---|
| 문자 단위 커서 이동 → 앞, 뒤, 맨 앞, 맨 뒤 | `Ctrl + F`(오른쪽), `Ctrl + B`(왼쪽), `Ctrl + A`(맨 앞), `Ctrl + E`(맨 뒤) |
| 단어 단위 커서 이동 → 앞, 뒤 | `Alt + F`(오른쪽), `Alt + B`(왼쪽) |
| 현재 위치 문자 삭제 | `Ctrl + D` 또는 `Delete` |
| 뒤에 있는 문자 삭제 | `Backspace` |
| 뒤에 있는 단어 삭제 | `Ctrl + W` |
| 자르기 및 붙여넣기 | `Ctrl + K`(현재위치에서 왼쪽 끝까지), `Ctrl + U`(오른쪽 끝까지), `Ctrl + Y`(붙여넣기) |
| 화면 잠금 및 해제 | `Ctrl + S`(화면 멈춤), `Ctrl + Q`(홤면 멈춤 해제) |
| 실행 종료 | `Ctrl + C` |
| 화면 삭제 | `Ctrl + L` |
