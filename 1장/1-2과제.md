## 1. 가상머신이란 무엇인가?

> 가상머신(VM)은 하나의 컴퓨터 안에서 소프트웨어를 이용해 별도의 컴퓨터와 운영체제 환경을 가상으로 만들어 사용하는 기술입니다.

## 2. 가상머신을 사용하는 이유를 설명하라.

> 가상머신은 하나의 컴퓨터에서 여러 운영체제를 사용할 수 있으며, 실제 시스템에 영향을 주지 않고 안전하게 개발이나 테스트를 할 수 있습니다.

## 3. WSL2가 다른 가상머신 소프트웨어와 비교하여 장점이 무엇인가?

> WSL2는 Windows에서 별도의 가상머신을 직접 관리하지 않아도 Linux 환경을 빠르고 간편하게 사용할 수 있다는 장점이 있습니다.

## 4. GUI, CLI의 장단점을 비교 설명하시오.

> GUI는 화면을 보면서 쉽게 사용할 수 있지만 자원을 많이 사용하고, CLI는 명령어를 알아야 하지만 빠르고 적은 자원으로 작업할 수 있습니다.

## 5. CLI 방식의 인터페이스가 GUI 방식보다 처리속도가 빠른 이유를 설명하라.

> CLI는 그래픽 화면을 표시하고 처리하는 과정이 필요하지 않아 시스템 자원을 적게 사용하기 때문에 GUI보다 빠르게 작업할 수 있습니다.

## 6. 리눅스에서는 왜 CLI 방식을 주로 사용하는가?

> 리눅스는 서버나 개발 환경에서 많이 사용되기 때문에 자원 사용이 적고 원격 제어와 자동화가 편리한 CLI 방식을 주로 사용합니다.

## 7. 리눅스 명령어란 무엇이고 중요 5개 명령어를 조사하라.

```bash
# 1. ls : 현재 디렉터리의 파일과 폴더 확인
$ ls

# 2. pwd : 현재 위치 확인
$ pwd

# 3. cd : 다른 디렉터리로 이동
$ cd Documents

# 4. mkdir : 새로운 디렉터리 생성
$ mkdir test

# 5. cp : 파일 복사
$ cp test.txt copy.txt
```
