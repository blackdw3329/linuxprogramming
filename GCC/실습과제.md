# 실습과제 1

## 1. 정적라이브러리와 동적라이브러리의 차이를 설명하라 → 정의, 링크시점, 장단점 등

> 정적 라이브러리는 빌드할 때 라이브러리 코드를 실행 파일에 포함하는 방식으로, 확장자는 `.a`입니다. 별도의 라이브러리 없이 실행할 수 있지만 실행 파일이 커지고, 라이브러리가 변경되면 다시 빌드해야 합니다.
>
> 동적 라이브러리는 프로그램을 실행할 때 라이브러리를 연결하는 방식으로, 확장자는 `.so`입니다. 여러 프로그램이 공유할 수 있어 용량을 절약하지만, 필요한 라이브러리가 없거나 버전이 맞지 않으면 실행되지 않을 수 있습니다.


| 구분 | 정적 라이브러리 | 동적 라이브러리 |
|---|---|---|
| 확장자 | `.a` | `.so` |
| 링크 시점 | 프로그램을 빌드할 때 | 프로그램 시작 또는 실행 중 |
| 실행 파일 크기 | 비교적 큼 | 비교적 작음 |
| 외부 라이브러리 필요 여부 | 실행할 때 필요 없음 | 실행할 때 필요함 |
| 라이브러리 공유 | 어려움 | 여러 프로그램이 공유 가능 |
| 장점 | 배포와 실행이 간단함 | 용량과 메모리를 절약할 수 있음 |
| 단점 | 라이브러리 변경 시 다시 빌드해야 함 | 라이브러리 누락이나 버전 충돌이 발생할 수 있음 |

## 2. gcc의 -I, -l, -L, -g, -v 옵션의 기능을 설명하라

> `-I` 옵션은 헤더 파일을 검색할 디렉터리를 지정합니다.

```bash
gcc -I./include -o program main.c
```

> `-l` 옵션은 링크할 라이브러리의 이름을 지정합니다. 예를 들어 `-lm`은 `libm` 수학 라이브러리를 연결합니다.

```bash
gcc -o program main.c -lm
```

> `-L` 옵션은 라이브러리 파일을 검색할 디렉터리를 지정합니다. 일반적으로 `-l` 옵션과 함께 사용합니다.

```bash
gcc -L./lib -o program main.c -lmylib
```

> `-g` 옵션은 실행 파일에 디버깅 정보를 포함합니다. GDB와 같은 디버거에서 변수, 함수, 소스 코드의 줄 번호를 확인할 때 사용합니다.

```bash
gcc -g -o program main.c
```

> `-v` 옵션은 GCC가 컴파일 과정에서 실행하는 명령과 컴파일러 정보를 자세하게 출력합니다.

```bash
gcc -v -o program main.c
```

## 3. 빌드 모드인 디버그모드(-g 옵션)와 릴리즈 모드(-O1,2,3 옵션)의 차이를 설명하라

> 디버그 모드는 `-g` 옵션을 사용하여 실행 파일에 디버깅 정보를 포함하는 방식입니다. 프로그램의 변수, 함수 호출 과정, 오류 발생 위치 등을 확인하기 쉽지만 실행 파일의 크기가 커질 수 있습니다.

```bash
gcc -g -o program main.c
```

> 릴리즈 모드는 최적화 옵션을 사용하여 프로그램의 실행 속도와 효율을 높이는 방식입니다. 최적화 과정에서 코드의 순서나 구조가 변경될 수 있으므로 디버깅은 어려워질 수 있습니다.

| 옵션 | 설명 |
|---|---|
| `-O1` | 기본적인 최적화를 수행하며 컴파일 시간이 비교적 짧음 |
| `-O2` | 실행 속도와 파일 크기를 고려하여 더 많은 최적화를 수행함 |
| `-O3` | 실행 속도를 높이기 위해 가장 적극적인 최적화를 수행함 |

```bash
gcc -O1 -o program main.c
gcc -O2 -o program main.c
gcc -O3 -o program main.c
```

# 실습과제 2

## 1. 정수 2개를 입력 받아 최대값을 구하여 출력하는 C언어 코드를 분할 컴파일 구조로 작성하라.(예제 2번을 참고할 것)

> 프로그램을 `max.h`, `max.c`, `main.c`로 분리하여 작성합니다. 입력, 최댓값 계산, 출력 기능을 각각 함수로 구현합니다.

### `max.h`

```c
#ifndef MAX_H
#define MAX_H

int data_input(void);             // 정수 한 개를 입력받는 함수
int find_max(int a, int b);       // 두 정수 중 최댓값을 구하는 함수
void data_print(int max_value);   // 최댓값을 출력하는 함수

#endif
```

### `max.c`

```c
#include <stdio.h>
#include "max.h"

int data_input(void)
{
    int number;                       // 입력받은 값을 저장할 변수

    printf("Input: ");                // 입력 안내문 출력
    scanf("%d", &number);             // 사용자에게 정수 입력받기

    return number;                    // 입력받은 정수 반환
}

int find_max(int a, int b)
{
    if (a > b)                        // a가 b보다 큰지 확인
        return a;                     // a가 크면 a 반환
    else
        return b;                     // 그렇지 않으면 b 반환
}

void data_print(int max_value)
{
    printf("Max: %d\n", max_value);   // 최댓값 출력
}
```

### `main.c`

```c
#include "max.h"

int main(void)
{
    int a, b, max_value;              // 입력값과 최댓값을 저장할 변수

    a = data_input();                 // 첫 번째 정수 입력
    b = data_input();                 // 두 번째 정수 입력
    max_value = find_max(a, b);       // 두 정수의 최댓값 계산
    data_print(max_value);            // 계산 결과 출력

    return 0;                         // 프로그램 정상 종료
}
```

# 실습과제 3

## 1. C++언어를 이용하여 실습과제1을 수행하시오.(예제 4번을 참고할 것)

> PDF에는 “실습과제1을 수행하시오”라고 적혀 있지만, 실습과제1은 이론 문제이고 예제 4번은 분할 구조의 C++ 프로그램입니다. 따라서 아래 답안은 실습과제2의 최댓값 프로그램을 C++ 분할 컴파일 구조로 작성한 것입니다.

### `max.hpp`

```cpp
#ifndef MAX_HPP
#define MAX_HPP

class MaxFinder
{
private:
    int a;                    // 첫 번째 입력값
    int b;                    // 두 번째 입력값
    int maxValue;             // 최댓값

public:
    void input();             // 정수 두 개를 입력하는 함수
    void findMax();           // 최댓값을 구하는 함수
    void print();             // 결과를 출력하는 함수
};

#endif
```

### `max.cpp`

```cpp
#include <iostream>
#include "max.hpp"

using namespace std;

void MaxFinder::input()
{
    cout << "Input: ";            // 첫 번째 정수 입력 안내
    cin >> a;                     // 첫 번째 정수 입력

    cout << "Input: ";            // 두 번째 정수 입력 안내
    cin >> b;                     // 두 번째 정수 입력
}

void MaxFinder::findMax()
{
    if (a > b)                    // a가 b보다 큰지 확인
        maxValue = a;             // a를 최댓값으로 저장
    else
        maxValue = b;             // b를 최댓값으로 저장
}

void MaxFinder::print()
{
    cout << "Max: " << maxValue << endl;   // 최댓값 출력
}
```

### `main.cpp`

```cpp
#include "max.hpp"

int main(void)
{
    MaxFinder maxFinder;          // MaxFinder 객체 생성

    maxFinder.input();            // 정수 두 개 입력
    maxFinder.findMax();          // 최댓값 계산
    maxFinder.print();            // 결과 출력

    return 0;                     // 프로그램 정상 종료
}
```
