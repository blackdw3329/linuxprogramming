

## ls 명령어의 4가지 옵션 -a, -l, -F, --help을 설명하고 각각 실행예를 첨부하시오.
실습용 빈 파일 생성 항목을 제외하고 번호를 다시 정리했습니다. 주석 1

## 1. `ls -a`

> 숨김 파일을 포함한 모든 파일과 디렉터리를 표시합니다. 현재 디렉터리인 `.`과 상위 디렉터리인 `..`도 표시합니다.

```bash
ls -a
```

```text
.  ..  file1  file2  file3  file4  file_a  file_ab  file_abc  file_abcd
```

## 2. `ls -l`

> 파일 종류와 권한, 하드 링크 수, 소유자, 그룹, 크기, 수정 시간, 파일 이름을 자세히 표시합니다. 실제 권한·소유자·시간은 환경에 따라 달라집니다.

```bash
ls -l file1
```

```text
-rw-r--r-- 1 student student 0 Sep 21 10:00 file1
```

## 3. `ls -F`

> 파일 이름 뒤에 종류를 나타내는 기호를 붙입니다. 디렉터리는 `/`, 실행 가능한 일반 파일은 `*`, 심볼릭 링크는 `@`로 표시합니다.

```bash
mkdir test_dir
ls -F
```

```text
file1  file2  file3  file4  file_a  file_ab  file_abc  file_abcd  test_dir/
```

## 4. `ls --help`

> `ls`의 사용법과 옵션 설명을 출력합니다.

```bash
ls --help
```

```text
-a, --all                  do not ignore entries starting with .
-l                         use a long listing format
 ... 설명이 더 있지만 생략
```

## 경로확장 문자 *, ?의 의미를 설명하고 각각 실행예를 첨부하시오.
## 1. 경로확장 문자 `*`

> `*`는 길이가 0 이상인 임의의 문자열과 일치합니다. 셸이 일치하는 파일 이름으로 확장하므로, `file*`는 이름이 `file`로 시작하는 파일들을 선택합니다. 기본 설정에서는 이름 맨 앞의 `.`은 일치시키지 않습니다.

```bash
ls file*
```

```text
file1  file2  file3  file4  file_a  file_ab  file_abc  file_abcd
```

```bash
ls file_a*
```

```text
file_a  file_ab  file_abc  file_abcd
```

## 2. 경로확장 문자 `?`

> `?`는 임의의 문자 정확히 한 개와 일치합니다. 따라서 `file?`는 `file` 뒤에 문자가 한 개 있는 파일을, `file_?`는 `file_` 뒤에 문자가 한 개 있는 파일을 선택합니다.

```bash
ls file?
```

```text
file1  file2  file3  file4
```

```bash
ls file_?
```

```text
file_a
```

```bash
ls file_??
```

```text
file_ab
```
