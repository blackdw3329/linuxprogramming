# 실습과제1

## 1. 디렉터리

> 파일과 다른 디렉터리를 저장하고 관리하는 공간으로, Windows의 폴더에 해당합니다.

## 2. 서브 디렉터리

> 특정 디렉터리 안에 포함된 하위 디렉터리입니다. 예를 들어 `/home/linux`에서 `linux`는 `/home`의 서브 디렉터리입니다.

## 3. 작업 디렉터리

> 현재 셸에서 작업 중인 디렉터리입니다. `pwd` 명령어로 위치를 확인하고, `cd` 명령어로 변경할 수 있습니다.

## 4. 홈 디렉터리

> 사용자 개인의 파일과 설정을 저장하는 기본 디렉터리입니다. 일반적으로 `/home/사용자명` 형태이며, 관리자 root의 홈 디렉터리는 보통 `/root`입니다.

## 5. `~`

> 셸에서 현재 사용자의 홈 디렉터리를 나타내는 기호입니다. 예를 들어 `cd ~`를 입력하면 자신의 홈 디렉터리로 이동합니다.

## 6. `.`

> 현재 디렉터리를 의미합니다. 예를 들어 `./script.sh`는 현재 디렉터리에 있는 `script.sh` 파일을 지정합니다.

## 7. `..`

> 현재 디렉터리의 상위 디렉터리를 의미합니다. 예를 들어 `cd ..`를 입력하면 한 단계 위의 디렉터리로 이동합니다.

## 8. `/`

> 경로의 맨 앞에서는 파일 시스템의 최상위인 루트 디렉터리를 의미하고, 경로 중간에서는 디렉터리와 파일 이름을 구분합니다. 예를 들어 `/home/linux`는 루트 아래의 `home` 디렉터리 안에 있는 `linux`를 나타냅니다.

## 9. 상대경로

> 현재 작업 디렉터리를 기준으로 파일이나 디렉터리의 위치를 나타내는 경로입니다. 예를 들어 `./file.txt`, `../Documents` 등이 있습니다.

## 10. 절대경로

> 루트 디렉터리 `/`부터 시작하여 파일이나 디렉터리의 전체 위치를 나타내는 경로입니다. 예를 들어 `/home/linux/file.txt`이며, 현재 작업 디렉터리가 달라져도 같은 위치를 나타냅니다.

# 실습과제2

## 1. 현재 작업 디렉터리에서 루트 디렉터리로 이동하는 절대경로 명령어는?

> `cd /`입니다. `/`는 루트 디렉터리의 절대경로입니다.

```bash
cd /
```

## 2. 현재 작업 디렉터리에서 루트 디렉터리로 이동하는 상대경로 명령어는?

> 현재 위치의 깊이에 따라 `..`를 반복하여 사용합니다. 예를 들어 현재 위치가 `/home/student`라면 `cd ../..`입니다. 먼저 `pwd`로 현재 위치를 확인해야 합니다.

```bash
pwd
cd ../..
```

## 3. `/usr/lib/gcc/x86_64-linux-gnu` 디렉터리로 이동하는 절대경로 명령어는?

> `cd /usr/lib/gcc/x86_64-linux-gnu`입니다. 경로 일부를 입력하고 `Tab` 키를 누르면 자동완성을 사용할 수 있습니다. 후보가 여러 개라면 문자를 더 입력하거나 `Tab`을 두 번 눌러 후보를 확인합니다.

```bash
cd /usr/lib/gcc/x86_64-linux-gnu
```

> 자동완성 입력 예: `cd /usr/li`까지 입력 → `Tab` → 이어서 `gcc/` 입력 → `x86` 입력 → `Tab` → 경로 확인 후 `Enter`.

## 4. `/usr/lib/gcc/x86_64-linux-gnu` 디렉터리로 이동하는 상대경로 명령어는?

> 출발 위치에 따라 달라집니다. 현재 위치가 루트 디렉터리 `/`라면 맨 앞의 `/`를 제외한 `cd usr/lib/gcc/x86_64-linux-gnu`입니다. 상대경로 입력에서도 `Tab`으로 자동완성할 수 있습니다.

```bash
cd usr/lib/gcc/x86_64-linux-gnu
```

> 현재 위치가 `/home/student`라면 `cd ../../usr/lib/gcc/x86_64-linux-gnu`를 사용합니다.
