
## 1. 셸변수와 환경변수의 차이점을 설명하라.

> **셸변수**는 현재 실행 중인 셸에서 사용하는 변수이며, 자식 프로세스에 자동으로 전달되지 않는다.
>
> **환경변수**는 외부 명령어와 자식 프로세스에도 전달되는 변수이다. `export` 명령어를 사용하여 셸변수를 환경변수로 설정할 수 있다.

```bash
MYNAME=ubuntu
echo $MYNAME
export MYNAME
bash -c 'echo "$MYNAME"'
```

## 2. 환경변수 PS1, PATH, SHELL, LANG을 출력하고 기능을 설명하라.

> 각 변수의 기능은 다음과 같다.
> | 변수 | 기능 |
> |---|---|
> | PS1 | 셸의 명령 프롬프트에 표시할 문자열을 설정한다. |
> | PATH | 명령어 실행파일을 검색할 디렉터리 경로를 저장한다. |
> | SHELL | 사용자의 기본 로그인 셸 경로를 저장한다. |
> | LANG | 언어, 지역, 문자 인코딩 등의 로케일을 설정한다. |
>
> PS1은 일반적으로 환경변수가 아닌 셸변수이지만 `echo` 명령어로 출력할 수 있다.

```bash
echo $PS1
echo $PATH
echo $SHELL
echo $LANG
```

## 3. 셸이 명령어 파일의 위치를 어떻게 찾는지 설명하라.

> 셸은 명령어가 입력되면 내장 명령어인지 확인하고, 외부 명령어인 경우 환경변수 `PATH`에 등록된 디렉터리를 순서대로 검색한다. 실행파일을 찾으면 실행하고, 찾지 못하면 오류를 출력한다.

```bash
echo $PATH
type -a ls
```

## 4. 셸스크립트를 설명하라.

> 셸스크립트는 여러 개의 셸 명령어를 하나의 파일에 작성하여 순차적으로 실행하도록 만든 프로그램이다. 반복 작업 자동화와 시스템 관리 등에 사용된다.

**셸스크립트 작성**

```bash
mkdir -p shell-lab
cd shell-lab
nano test.sh
```

**test.sh**

```bash
#!/bin/bash
echo "Hello Ubuntu"
echo "Shell Script Test"
```

## 5. 셸스크립트의 실행방법 3가지를 조사하라.

> 셸스크립트는 `bash` 명령어를 사용하는 방법, 실행 권한을 부여하여 직접 실행하는 방법, `source` 명령어를 이용하는 방법으로 실행할 수 있다.

**bash 명령어를 이용하는 방법**

```bash
bash test.sh
```

**실행 권한을 부여하고 직접 실행하는 방법**

```bash
chmod +x test.sh
./test.sh
```

**source 명령어를 이용하는 방법**

```bash
source test.sh
```

## 6. .bashrc 파일에 환경변수 MYVER을 선언하고 값을 ubuntu 26.04으로 설정하는 코드를 추가하고 .bashrc 파일을 다시 실행(source)하라. 그리고 환경변수 MYVER의 값이 잘 설정되었는지 명령어(echo)로 확인하라

> `.bashrc` 파일에 `export` 명령어를 사용하여 환경변수 MYVER을 선언한다. 이후 `source` 명령어로 변경된 설정을 현재 셸에 적용하고 `echo` 명령어로 값을 확인한다.

**① .bashrc 파일 열기**

```bash
nano ~/.bashrc
```

**② 파일 마지막 줄에 추가할 코드**

```bash
export MYVER="ubuntu 26.04"
```
<img width="796" height="329" alt="image" src="https://github.com/user-attachments/assets/a517107d-bf36-410e-80cb-90d5daec1240" />

**③ .bashrc 파일 다시 실행**

```bash
source ~/.bashrc
```

**④ 환경변수 값 확인**

```bash
echo $MYVER
```

## 7. 환경변수에 경로를 추가할 때 $ PATH=‘$PATH:~/bin’ 처럼 작성하면 어떻게 되는지 설명하라.

> 작은따옴표를 사용하면 `$PATH`와 `~`가 확장되지 않고 문자 그대로 저장된다. 따라서 기존 PATH 경로가 유지되지 않아 외부 명령어 실행에 문제가 발생할 수 있다.
>
> 기존 PATH를 유지하면서 홈 디렉터리의 `bin` 경로를 추가하려면 큰따옴표와 `$HOME`을 사용해야 한다.

<img width="981" height="115" alt="image" src="https://github.com/user-attachments/assets/2193ed98-bfed-4bb4-ac8f-45aa2eb76a44" />


**올바른 설정 방법**

```bash
export PATH="$PATH:$HOME/bin"
echo $PATH
```
