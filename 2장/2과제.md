## 1. 리눅스 명령어가 무엇인지 설명하시오. 또, 실제 명령어의 정체는 무엇인가?

> 리눅스 명령어는 셸에 입력하여 파일 관리, 프로그램 실행 등의 작업을 지시하는 명령입니다. 실제 정체는 실행 파일이나 스크립트, 셸에 포함된 내장 기능 등이며, 함수나 별칭으로 정의되기도 합니다.

## 2. 리눅스에서 가장 많이 사용되는 명령어 10개를 조사하고 설명하시오. 또, 셸에서 실행하고 결과를 첨부하시오.

> 자주 사용하는 대표적인 명령어로는 현재 위치를 확인하는 `pwd`, 파일 목록을 표시하는 `ls`, 디렉터리를 이동하는 `cd`, 디렉터리를 생성하는 `mkdir`, 빈 파일을 만들거나 시간을 갱신하는 `touch`, 파일을 복사하는 `cp`, 파일을 이동하거나 이름을 변경하는 `mv`, 파일을 삭제하는 `rm`, 파일 내용을 출력하는 `cat`, 특정 문자열을 검색하는 `grep`이 있습니다. 현재 환경에서는 리눅스 셸을 실행하지 못했으므로 실제 실행 결과는 첨부하지 못했습니다.

## 3. 셸과 커널을 구분하여 자세히 설명하시오.

> 셸은 사용자가 입력한 명령어를 해석하고 프로그램을 실행하는 명령 해석기이며, 변수·반복문·파이프 등을 이용한 작업 자동화도 지원합니다. 커널은 운영체제의 핵심으로 CPU, 메모리, 프로세스, 파일 시스템, 장치 등을 관리합니다. 셸과 프로그램은 시스템 호출을 통해 커널의 기능을 이용하며, 셸은 사용자 공간에서, 커널은 커널 공간에서 동작합니다.

## 4. 프롬프트 문자열에서 문자 `~`의 의미를 조사하시오.

> 프롬프트의 경로에 표시되는 `~`는 일반적으로 현재 사용자의 홈 디렉터리를 의미합니다. 예를 들어 홈 디렉터리가 `/home/student`라면 `~`는 `/home/student`, `~/Documents`는 `/home/student/Documents`를 나타냅니다. 명령어에서도 `cd ~`를 입력하면 자신의 홈 디렉터리로 이동할 수 있습니다.

## 5. sh, bash, zsh 셸의 차이를 자세히 조사하시오.

> `sh`는 전통적인 Bourne 셸의 이름이며, 오늘날에는 보통 POSIX 표준 셸을 실행하는 명령으로 사용됩니다. 실제 구현은 시스템에 따라 다릅니다. `bash`는 Bourne 셸을 확장하여 명령어 기록, 자동 완성, 배열 등의 기능을 제공하는 셸입니다. `zsh`는 정교한 자동 완성, 파일 이름 패턴 처리, 프롬프트 설정 등 대화형 사용에 강점이 있습니다. 세 셸의 기본 문법은 비슷하지만 확장 기능과 동작에 차이가 있어 스크립트가 항상 호환되지는 않습니다.

## 6. 셸 스크립트에 대하여 자세히 조사하시오.

> 셸 스크립트는 여러 명령어를 텍스트 파일에 작성하여 셸이 해석하고 실행하도록 만든 프로그램입니다. 변수, 조건문, 반복문, 함수를 사용하여 백업, 파일 정리, 프로그램 실행 등의 반복 작업을 자동화할 수 있습니다. 첫 줄의 `#!/bin/bash`와 같은 표기는 직접 실행할 때 사용할 해석기를 지정합니다. `bash script.sh`로 실행하거나, `chmod +x script.sh`로 실행 권한을 부여한 뒤 `./script.sh`로 실행할 수 있습니다.

## 7. Windows에서 사용하는 CLI 방식의 셸의 종류를 조사하시오.

> 대표적으로 명령 프롬프트인 `cmd.exe`, Windows PowerShell, PowerShell 7이 있습니다. `cmd.exe`는 기본 명령어와 배치 파일을 실행하며, PowerShell은 객체 기반 명령 처리와 스크립트를 통해 시스템 관리 및 자동화를 지원합니다. 추가로 Git Bash를 설치하거나 WSL 환경에서 Bash, Zsh 등을 사용할 수 있습니다. Windows Terminal은 이러한 셸을 실행하는 터미널 프로그램이며, 셸 자체는 아닙니다.
